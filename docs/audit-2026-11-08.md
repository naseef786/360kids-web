# Web preview audit — 8 November 2026

Scope: the local `360kids-web` frontend, its locked dependencies, preview navigation, saved inspiration, and responsive/accessibility behavior. This does not certify the unimplemented backend or production authorization.

## Findings addressed

| Finding | Fix |
| --- | --- |
| The preview server had been stopped, leaving the user's open page unavailable. | Restarted the loopback-only development server and verified it in the built-in browser. Kept it running for review. |
| Saving an activity on one Parent route lost the save on navigation to the other route. | Shared browser-tab session storage, SSR-safe subscriptions, guarded parsing and storage access, and a memory fallback. Only known sample IDs contribute to the displayed count. |
| Repeated activity controls had indistinguishable accessible names. | Added per-activity names for disclosures and save/remove buttons, plus live saved-count feedback. |
| The keyboard skip destination was not explicitly focusable. | Made the main workspace focusable; browser inspection confirmed the skip link transfers focus to it. |
| Fixed sidebar content could become unreachable in short desktop windows. | Enabled sidebar scrolling and prevented its content from shrinking. Verified the sidebar is scrollable at 1366 × 540. |
| Small navigation and activity controls were difficult to target. | Raised their minimum height to 44px. Inspected the mobile layout at 390px width. |
| Every role route had the same browser title. | Added distinct page metadata while preserving inherited noindex settings. |
| The parser's minimatch dependency carried a moderate denial-of-service advisory. | Scoped override to minimatch 11.0.1 under `@typescript-eslint/typescript-estree`; updated the npm lockfile and validated the CommonJS matcher API used by the parser. |

The dependency override is deliberately limited to the affected parser dependency. Its upstream package still declares minimatch 10; remove the override once it supports a patched release. Reference: [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249).

## Verification

- Repository lint, typecheck, production build, and whitespace checks passed.
- A fresh npm audit reported zero known vulnerabilities across the dependency tree.
- All seven app routes returned HTTP 200, distinct role-page titles were present, and noindex was retained.
- An unknown route returned HTTP 404.
- Browser checks covered saving an activity, navigating from Activities to Overview, refreshing, switching roles and back, and filtering to Movement. Saved inspiration remained available after navigation and reload; filtering showed only the matching activity.
- Keyboard skip focus, mobile rendering, and desktop overflow were inspected. The desktop document did not exceed the test viewport width.
- Four matcher checks covered TSX matches, dot directories, nonmatching extensions, and generated-directory globs after the dependency override.

## Remaining product work

Authentication, server-side authorization, tenant isolation, real catalog data, requests, payments, and partner approval are not implemented. The preview contains fictional records and no live privileged actions. Connect those features through `360kids-backend` before using real family or partner data. No deployment or GitHub push was performed by this audit.
